# Beslutsregler

Siffror som agenterna tillämpar mekaniskt. Justera efter din budget och dina verkliga avgifter.

## Produktkrav
| Regel | Värde |
|---|---|
| Lägsta pris till kund (inkl. moms) | 249 kr |
| Pris ≥ landad kostnad × | 3 |
| Minsta bidrag per order före annonser | 120 kr |
| Max break-even-ROAS | 2,5 |
| Max leveranstid till kund | 12 dagar (föredra EU-lager) |
| Leverantörsbetyg | ≥ 95 %, ≥ 1 000 sålda |

## Kostnadsantaganden (kontrollera mot dina avtal)
| Post | Antagande |
|---|---|
| Moms | 25 % (pris exkl. moms = pris × 0,8) |
| Betalavgift | 3 % + 3 kr per order ⚠️ beror på plan och betalsätt |
| Returer/reklamationer | 8 % av pris exkl. moms |
| EU-tull småpaket (< 150 €) | fast avgift per varupost sedan 1 juli 2026 ⚠️ kontrollera aktuellt belopp hos Tullverket |

## Annonstest (Meta/TikTok)
| Regel | Värde |
|---|---|
| Testbudget per produkt | 150 kr/dag i 3–4 dagar |
| Max produkter i test samtidigt | 2 |
| **Döda kreativ** | spenderat ≥ 1 × break-even-CPA och 0 köp, eller CTR < 0,8 % efter 1 000 visningar |
| **Döda produkt** | spenderat ≥ 2,5 × break-even-CPA och ROAS < 1,0 |
| **Skala** | ROAS ≥ 1,3 × break-even-ROAS i 3 dagar i rad → +20 % budget per dag |
| Stopp-förlust totalt | användarens månadsbudget i `.claude/product-marketing.md` |
