# Kontopaket: klicka igenom på cirka 30 minuter

Allt du ska skriva in står här. Gör stegen i ordning: mejlen först, eftersom alla andra konton kopplas till den.

**Innan du börjar**
- Ha mobilen nära (SMS-koder).
- Använd en lösenordshanterare (Bitwarden är gratis) och ett **unikt lösenord per konto**.
- Slå på **tvåstegsverifiering** på alla konton direkt. Ett kapat TikTok- eller Shopify-konto är det dyraste som kan hända butiken.
- Filer: `profilbild-1000x1000.png` (rund profilbild) och `logo-1000x1000.png` (med namn) i den här mappen.

---

## 1. Mejl (gratis)
**Nu:** skapa ett Gmail-konto på gmail.com.
| Fält | Värde |
|---|---|
| Förnamn / efternamn | Vildpuls / Butik |
| Adress | `vildpuls.butik@gmail.com` (alternativ: `hej.vildpuls@gmail.com`, `vildpuls.se@gmail.com`) |

**Senare (när du köpt vildpuls.se):** skaffa `hej@vildpuls.se`, antingen via domänleverantörens e-post/vidarebefordran eller ett gratis/billigt e-postkonto för egen domän, och byt sedan kontaktmejl på alla konton.

## 2. Shopify
shopify.com/se → Starta gratis provperiod → välj **Starter** när provperioden tar slut.
| Fält | Värde |
|---|---|
| E-post | Gmail-adressen ovan |
| Butiksnamn | Vildpuls |
| Land / valuta | Sverige / SEK |
| Vad säljer du? | Produkter jag köper eller tillverkar → Dropshipping |
| Kontaktmejl för kunder | Gmail-adressen (byt till hej@vildpuls.se senare) |

Sedan: Inställningar → Betalningar → aktivera Shopify Payments (kräver personnummer/org.nr och bankkonto). Klistra in sidorna enligt `butik/START-CHECKLISTA.md`. Installera apparna **DSers**, **Facebook & Instagram**, **TikTok** och **Pinterest** (alla gratis).

## 3. Instagram (+ Facebook-sida)
1. Skapa en Facebook-sida: Namn `Vildpuls`, Kategori `Sport- och friluftsbutik`, profilbild = profilbild-1000x1000.png
2. Instagram → nytt konto med Gmail-adressen → användarnamn **@vildpuls** (alternativ: `@vildpuls.se`, `@vildpulsbutik`, `@vild.puls`)
3. Inställningar → Kontotyp → **Professionellt → Företag** → koppla till Facebook-sidan
| Fält | Värde |
|---|---|
| Namn | Vildpuls · Friluftsprylar |
| Bio | `Prylar som får dig ut oftare 🌲 Vandring · löpning · camping 👇` |
| Länk | din Shopify-länk / länk-i-bio-sida |
| Kategori | Sport- och friluftsbutik |

## 4. TikTok
tiktok.com → Registrera med Gmail-adressen → Inställningar → Konto → **Byt till företagskonto** → kategori *Sport & friluftsliv*.
| Fält | Värde |
|---|---|
| Användarnamn | **@vildpuls** (samma alternativ som ovan, använd samma namn överallt) |
| Namn | Vildpuls 🌲 |
| Bio | `Ut och lev 🏃⛺ Smarta prylar för vardagsäventyr. Shoppa här 👇` |
| Länk | Shopify-länken |

## 5. Pinterest
business.pinterest.com → Skapa företagskonto med Gmail-adressen.
| Fält | Värde |
|---|---|
| Företagsnamn | Vildpuls |
| Användarnamn | vildpuls |
| Om | `Inspiration och smarta prylar för vandring, camping och löpning i Sverige. Ut oftare, ha roligare där ute 🌲` |
| Webbplats | Shopify-butikens adress (gör "Gör anspråk på webbplats" via Shopifys Pinterest-app) |
| Mål | Sälja fler produkter, Sverige, budget "Jag vet inte än" |

Koppla Shopifys **Pinterest-app**: då blir alla produkter automatiskt köpbara pins (gratis) och Pinterest-taggen installeras.
