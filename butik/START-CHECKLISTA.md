# Startchecklista: det här behöver du göra själv

Teamet har förberett texterna. De här stegen kräver dig (konton, betalning, juridik). Räkna med cirka 3–4 timmar totalt.

## 1. Företag (gratis via verksamt.se)
- [ ] Registrera enskild firma och ansök om **F-skatt och momsregistrering** hos Skatteverket. Du behöver ett org.nr innan du säljer i större skala och för att få ta ut moms korrekt.
- [ ] Separat bankkonto eller kort för butiken (gör bokföringen enkel)

## 2. Konton (cirka 5 USD/mån totalt)
- [ ] Skapa Shopify, välj **Starter**-planen
- [ ] Aktivera Shopify Payments, valuta SEK, Sverige som marknad
- [ ] Installera **DSers** (gratisplan) och koppla ditt AliExpress-konto
- [ ] Logga in i DSers MCP från Claude Code en gång (`/mcp` → dsers → logga in), så kan inköparen söka leverantörer
- [ ] (Valfritt) Köp domänen **vildpuls.se** (cirka 100–200 kr/år) eller kör på Shopifys gratisadress i början

## 3. Sociala konton (gratis)
- [ ] TikTok **företagskonto** @vildpuls (eller närmaste lediga)
- [ ] Instagram professionellt konto + Facebook-sida (krävs för Instagram-shopping)
- [ ] Klistra in profiltext och länk-i-bio från `butik/sidor/grund/lank-i-bio.md`

## 4. Klistra in sidorna i Shopify
Fyll i alla [HAKPARENTESER] (företagsnamn, org.nr, adress, e-post, fraktpris), sedan:
- [ ] `om-oss.md`, `kontakt.md` → Sidor
- [ ] `kopvillkor.md`, `frakt-och-retur.md`, `integritetspolicy.md` → Inställningar → Policyer
- [ ] Slå på Shopifys cookie-banner (Inställningar → Kundsekretess)

## 5. Sen
- [ ] Be Claude: **"/dropship-team hitta-produkter"**
